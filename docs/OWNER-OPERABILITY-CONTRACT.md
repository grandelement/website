# Owner operability and maintenance contract
The owner must be able to operate GE Studios without coding or AI.
## Back Room
Provide plain-language settings, descriptions, defaults, validation, preview, publish confirmation and rollback. Clearly distinguish public settings from personal preferences. Include a searchable built-in owner manual and system map. Never expose credentials or bypass access controls.
## System Health
Display last successful checks, deployment version, component status, unresolved failures and repair history. Check catalog integrity, configuration consistency, links, controls, playback, offline storage, sharing, responsive layout and access boundaries. Distinguish automated simulation from actual device verification.
## Recovery
Use scheduled external checks independent of visitor sessions. A browser cannot guarantee continuous execution. Use bounded retries, verified failover, cache recovery and last-known-good configuration. Never automatically erase downloads, playlists, fan records or credentials. Code repairs require isolated tests, reviewed changes and verified deployment; no unrestricted self-modifying production code.
## Documentation
Maintain an owner-facing manual in Back Room, an exportable copy, configuration reference, dependency map, backup/restore instructions, and emergency recovery procedure. Update documentation and regression tests with each functional change.
## Acceptance
Owner can change settings, understand health status, restore a known-good configuration, and operate music, radio and playlists without editing source code. Keep operating costs and external dependencies visible. No claim of autonomous recovery until tested.
