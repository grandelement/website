    INSTALL MP3 ENCODER · LEGACY INTEL MAC

    This downloads the standalone LAME 3.99 command-line encoder listed by RareWares for Intel 64-bit OS X Lion and later. It must be made executable and the updated iMac upload helper restarted before MP3 conversion becomes available.

    Unchecked: upload the original WAV, AIFF, MP3 or other supported file unchanged. Checked: convert locally to a 320 kbps MP3 (requires FFmpeg or, for WAV/AIFF, LAME). If no compatible encoder is installed, conversion is blocked rather than silently uploading the wrong format. The original remains on this iMac.

    SELECT SEVERAL TRACKS · Hold Command or Shift in the file picker to select multiple files. They upload one after another. If an Upload button does not open a file window, use the visible Choose File control below.

    The bar moves during conversion and transfer even when an exact percentage is not available. 100% appears only after Google Drive confirms completion.

    My Drafts and My Finals show stored tracks. The newest helper also lets you move a selected Google Drive file to Trash.

    DOWNLOAD UPDATED IMAC HELPER · Required for MOVE TO TRASH and improved upload progress. Save as ge-upload-helper-v2.py in Downloads. Stop the old helper in Terminal with Control+C, then run python ~/Downloads/ge-upload-helper-v2.py. The GE DJ Booth itself stays open.

    MP3 SETUP: After downloading lame-3.99 to Downloads, run chmod +x ~/Downloads/lame-3.99 and verify with ~/Downloads/lame-3.99 --version. Then restart the updated ge-upload-helper-v2.py.
