MUSIC BUTTON DEFAULT ORDER Top row: - Prev - Next Second row: - Shuffle - Legacy - Share NOTE: - Prev / Next are the most important thumb controls. - Shuffle / Legacy / Share are secondary. - Text must remain large and readable. BACKGROUND DEFAULT ORDER Top row: - Off - Prev - Next Second row: - Per Song - Shuffle - Auto UTILITY ROW - Reload Library = left - Offline / Offline Ready = center - Hide Text combined control = right HIDE TEXT - ONE combined control only. - Inside the control is a small checkbox. - Visible text says only: Hide Text - Clicking/tapping the main button manually hides text/HUD immediately. - Checkbox checked = Auto Hide enabled. - Checkbox unchecked = text stays visible unless manually hidden. - Do not add a second Auto Hide button. BANDCAMP - Secondary / small control. - Centered below utility row. - Much smaller than major playback controls. - "Buy on" / "Bandcamp" may use two lines. ARRANGE BUTTONS - Optional Arrange Buttons / Lock Buttons mode. - In edit mode the selected button must physically lift and FOLLOW THE USER'S FINGER. - Other buttons should move/reflow underneath the dragged button. - On release, the button drops into the nearest valid position. - Prevent accidental text selection/callout while arranging. - Never allow a control to disappear off-screen. - Never allow controls to overlap permanently. - Save portrait and landscape arrangements separately. - Default arrangement above must remain available/resettable. ============================================================ 2. SHIP VIEW — CORE LAYER MODEL ============================================================ THIS IS CRITICAL. The cockpit must behave as separate visual layers: A. FIXED FOREGROUND - cockpit frame - windshield/glass frame/mask - dashboard - physical cockpit panels These NEVER move when steering. B. MOVING SCENE BEHIND WINDSHIELD - current background image - blue Grand Element sun / target - arrival lake transition - atmosphere/cloud effects - warp effects These move behind the fixed cockpit. C. HUD / OVERLAYS - target reticle - analysis bubble - Maximum Speed / Warp notice - projected EQ/spectrum These remain clipped to windshield unless intentionally located on cockpit instruments. The windshield itself must NEVER slide, tilt, translate, or expose black gaps when the attitude stick moves. ============================================================ 4. SHIP CONTROLS ============================================================ RIGHT THROTTLE - Millennium Falcon style vertical throttle. - Neutral middle. - Reverse below. - Cruise forward above. - Top portion becomes Warp / Maximum Speed. - No volume-slider appearance. - Large physical handle. - Forward and reverse should have comparable maximum travel rate. - User must be able to zoom out as quickly as zooming in. LEFT ATTITUDE / DIRECTION CONTROL - Controls heading / orientation. - Up/down/left/right. - It must NOT move the glass or cockpit. - It moves the scene: - blue sun moves the most - background moves a smaller amount (parallax) - radar target position updates consistently - It should feel like steering a ship toward/away from a target. AUTO PILOT - Small On/Off button in lower-right cockpit area. - Green/active state when on. - Auto Pilot may: - locate target - steer toward it - accelerate / cruise / warp - decelerate near arrival - manage atmospheric entry - run occasional scans - Manual steering/throttle can disengage it if desired. ============================================================ 5. SHIP PLAYBACK / CONTROLS ============================================================ - Previous / Play / Next cockpit buttons must sit LOWER inside the center dashboard recess. - Latest request: move them down another ~15-30% from the current position if needed. - Buttons should be shaped to match cockpit geometry rather than large generic circles. - Track title stays fitted in the upper cockpit title area. - Time/progress stays above playback buttons without colliding with them. SHIP HIDE CONTROL - Text should say: Hide Ship - Combined with checkbox model if auto-hide is used. - Hiding Ship should hide cockpit/HUD controls as specified, but ALWAYS leave the current visual/background scene visible. - Maximum Speed / Warp notice must hide with Hide Ship. - Player View button should also hide with Hide Text/Ship when appropriate. ============================================================ 6. SHIP RADAR / TARGETING ============================================================ LEFT RADAR DISPLAY - Radar stays aligned to actual lower-left circular cockpit screen. - Radar target scale must match target distance model. - As blue sun gets farther away, radar target gets smaller. - As blue sun approaches, radar target grows / moves consistently. TAP RADAR - Tapping the radar MUST immediately call up the windshield target system. - The target reticle must lock onto the ACTUAL CURRENT BLUE SUN POSITION. - It must follow the blue sun after steering. - It must remain clipped to the windshield only. - It must never draw across dashboard/cockpit surfaces. TARGET READOUT Preferred label: - Target Range or - Distance to Object Analysis can include: - target range - ETA - vector - resonance - dimensional pressure - harmonic field density - electrical field saturation - molecular resonance - life-force signature - atmosphere readings during final approach RANDOM ANALYSIS - Keep occasional automatic analysis events. - They must be irregular enough that a predictable pattern is not obvious. - Radar tap triggers analysis immediately even if an automatic event is not due. ============================================================ 7.
